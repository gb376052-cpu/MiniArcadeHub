# 🎮 Mini Arcade Hub

A feature-rich, lightweight, and modern **Mini Arcade Hub** built with vanilla HTML, CSS, and JavaScript. It features multiple classic arcade games packaged into a single, responsive dashboard with a sleek dark-mode UI.

---

## ✨ Features

- **🧭 Centralized Hub Dashboard:** Easily switch between different games with a smooth menu layout.
- **❌⭕ Tic-Tac-Toe Pro:** 
  - Supports both **2-Player** and **vs AI** modes.
  - Adjustable board sizes (3x3, 4x4, 5x5).
  - Multiple AI difficulty levels (Easy, Medium, Hard).
- **✊✋ Rock Paper Scissors:**
  - Classic gameplay with emoji UI.
  - Custom difficulties including **Easy**, **Normal**, and **Hard (Cheating CPU)** modes!
- **🃏 Memory Match:**
  - Test your memory skills with customizable grid pairs (Easy, Medium, Hard).
- **🔢 Number Guessing:**
  - Range-based number puzzles with attempt limits across multiple difficulties.
- **🐍 Retro Snake:**
  - Classic grid-based snake game with customizable snake skins and keyboard controls.

---

## 🛠️ Tech Stack

- **HTML5** - Structure and layout
- **CSS3** - Styling, Flexbox/Grid, and Glassmorphism effects
- **JavaScript (ES6+)** - Game logic and dynamic DOM manipulation
